# West Coast IR — Website

Source code for the West Coast Interventional Radiology website, hosted via GitHub Pages.

**Live site:** https://InterventionalRadiologist.github.io/

## Structure

- `index.html` — Home page
- `about.html` — About / approach page
- `procedures.html` — Full procedures list, organized by category
- `contact.html` — Contact page
- `appointments.html` — Booking page
- `styles.css` — Shared stylesheet used by all pages
- `icons/` — Procedure category icons and logo mark

## Editing the site

1. Open the relevant `.html` file directly on GitHub (click the pencil/edit icon).
2. Make your changes.
3. Commit — the live site updates automatically within a minute or two.

For style changes (colors, fonts, spacing), edit `styles.css` — changes there apply across every page.
